━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1 — DEPLOY THE WEBSITE (5 mins)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to vercel.com → sign up free
2. Click "Add New Project"
3. Choose "Deploy without a repository"
4. Drag and drop the INDEX.HTML file
5. Vercel gives you a live URL instantly ✓

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2 — CONNECT shyftrota.com (10 mins)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Vercel:
1. Project → Settings → Domains
2. Add: shyftrota.com
3. Copy the DNS records Vercel shows you

In Namecheap:
1. Log in → Domain List → Manage (shyftrota.com)
2. Advanced DNS → Add the records from Vercel
3. Save → wait 5–30 mins → site is live at shyftrota.com ✓

STEP 3 — DEPLOY THE APP (when ready)
